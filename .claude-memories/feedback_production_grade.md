---
name: Always choose production-grade tools
description: Student wants mid/senior level backend practices — no toy setups, always use production tools and best practices
type: feedback
---

Always choose production-grade, scalable tools over simplified alternatives. No SQLite — use PostgreSQL. No shortcuts that wouldn't survive a real project.

**Why:** Student is aiming for mid/senior backend level and will work on real projects. Every decision should reflect what a production team would choose. Learning with toy tools teaches bad habits.

**How to apply:** When making technology or setup decisions, always default to the production choice: PostgreSQL over SQLite, Docker for services, proper config/env management, etc. If there's a simpler option and a production option, always pick production and teach why.
